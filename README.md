# TIROCINIO UNISA

## Degenerate Strings Applied to Bioinformatics

Progetto di tirocinio curriculare in Informatica presso l'Università degli Studi di Salerno (UNISA).

### Obiettivo

Studiare le stringhe degeneri (*Degenerate Strings*) e le loro applicazioni nell'ambito della bioinformatica, con particolare attenzione alla rappresentazione e alla costruzione di automi finiti.

### Argomenti principali

- Stringhe degeneri e alfabeti biologici.
- Pattern matching su sequenze biologiche.
- Automi finiti non deterministici (NFA).
- Costruzione di automi deterministici (DFA).
- Minimizzazione degli automi.
- Applicazioni nell'analisi di sequenze di DNA.

### Struttura del progetto

La struttura e i contenuti del repository verranno aggiornati durante lo svolgimento del tirocinio.
